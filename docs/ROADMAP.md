# Roadmap

- [x] **Hito 1** — Shell, sidebar, páginas anidadas, título autoguardado, favoritos, papelera, API.
- [x] **Hito 2** (base) — Editor de bloques (TipTap), comandos `/`, atajos, formatos, autoguardado de contenido. Pendiente: menú flotante de formato, arrastrar bloques, menú de bloque, imágenes/tablas/colores.
- [x] **Hito 3** — Mover/reordenar (dnd-kit), búsqueda, duplicar, iconos, menú contextual, tema oscuro. Pendiente: historial de versiones, selección múltiple.
- [x] **Hito 4** — Bases de datos: propiedades (incl. relación, rollup, fórmula, archivos), filtros, orden, agrupación, cálculos; vistas tabla, tablero, calendario, galería, lista, cronograma; plantillas. Pendiente: ventana lateral, barras de cronograma arrastrables, propiedad Personas (Hito 5).
- [ ] **Hito 5** — Autenticación, workspaces, usuarios, permisos.
- [x] **Hito 6** — Colaboración en tiempo real (Yjs + WebSockets), comentarios, menciones.
- [ ] **Hito 7** — Refinamiento visual, accesibilidad, rendimiento, regresión visual contra Notion.
